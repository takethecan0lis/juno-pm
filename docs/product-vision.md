# Juno product vision

**One-line pitch:** Juno is an AI associate PM that reads a product leader's backlogs, finds the work that is ready to run without them, and delivers one ranked digest of calls they can accept in a single decision each.

**Vision statement**

Juno is for a product leader who runs many projects and cannot check every backlog. Work sits waiting because nobody has time to see which items already meet the Definition of Ready, and which need a quick spike to get there.

Each run, Juno reads every permitted backlog, finds ready work that needs no input from you, runs short scratch-only spikes on items that are close, and delivers one digest ranked by WSJF. It recommends. It never edits a backlog, sends, spends or deletes.

What makes Juno different is its harness, not its model. Autonomy is bounded: capped turns, capped cost, a scratch folder, and a human decision on anything larger. Every call cites its source file and each criterion it meets, and a separate checker compares those claims to the files. Anything that fails is labelled unverified, never dropped. Any WSJF score Juno invents is labelled an estimate, with its inputs shown.

The outcome: you accept most of what Juno calls ready, one decision each, and trust it because you can see why.
