# Juno PM supporting documents

The graded artifacts are in the five numbered module folders at the top of this repo. These documents sit beside them and explain the product thinking behind Juno. Everything here is a design on paper: nothing is built, and every number is an assumption unless the document says where it came from.

| Document | What it answers |
|---|---|
| [product-vision.md](product-vision.md) | Who Juno is for, the problem, what it does, and the outcome |
| [business-hypothesis.md](business-hypothesis.md) | The value of Juno, the jobs to be done, the product breakdown, and the business hypothesis with how it could be proven wrong |
| [success-metrics-plan.md](success-metrics-plan.md) | The north star metric, supporting metrics, guardrails, baselines and targets |
| [risk-register.md](risk-register.md) | The main risks, the controls already in the harness, the gaps, and the lines that never move |
| [architecture-overview.md](architecture-overview.md) | The shape of the system, which boundaries the tool enforces, and the decisions behind them |
