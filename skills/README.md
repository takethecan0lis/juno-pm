# Juno PM skills

Four skills Juno relies on, written in the same four-part skill file format as Module 1 (Role, Task, Constraints, Format, with a worked example). They are adopted routines, not measured ones: no result is claimed for any of them.

| Skill | Where Juno uses it |
|---|---|
| [wsjf-cost-of-delay.md](wsjf-cost-of-delay.md) | Ranks work by economics on a 1 to 13 scale, with estimates always labelled |
| [needs-you-block.md](needs-you-block.md) | The digest's section for what needs the leader, capped at three asks |
| [not-verified-build-report.md](not-verified-build-report.md) | The "what this did not verify" part of every digest and handover |
| [decision-digest.md](decision-digest.md) | The shape of the digest the leader reads and answers |

These four come from a separate, larger set of general skills at [github.com/takethecan0lis/ai-pm-skills](https://github.com/takethecan0lis/ai-pm-skills), licensed CC BY 4.0, attribution Drew Podwal.
